# 🃏 MYTHORIA — Jeu de cartes Dark Fantasy

## 📖 Présentation du projet

Mythoria est un site web dédié à un jeu de cartes à collectionner dans un univers Dark Fantasy. Les joueurs peuvent découvrir des boosters, gérer leur panier et, dans les prochaines étapes, ouvrir des boosters, collectionner des cartes et composer leur propre deck.

## 📦 Livrable du jour 4 — Ouverture des boosters

### 🎯 Objectif
Développer un système permettant au joueur d’ouvrir un booster et de découvrir des cartes obtenues aléatoirement.

### ⚙️ Fonctionnalités attendues
- Permettre au joueur de sélectionner un booster.
- Générer des cartes aléatoires à partir du catalogue JavaScript.
- Afficher les cartes obtenues après l’ouverture.
- Ajouter les cartes obtenues à la collection du joueur.
- Vérifier que le système fonctionne correctement.

### 🛠️ Technologies utilisées
- HTML5 pour la structure.
- Tailwind CSS pour le design.
- JavaScript pour la logique d’ouverture aléatoire.
- LocalStorage pour conserver les cartes obtenues, si cette fonctionnalité est implémentée.

### 📋 Résultat attendu
Une interface permettant d’ouvrir un booster et d’afficher les cartes obtenues aléatoirement.
