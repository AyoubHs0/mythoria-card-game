# 🃏 MYTHORIA — Jeu de cartes Dark Fantasy

## 📖 Présentation du projet

Mythoria est un site web dédié à un jeu de cartes à collectionner dans un univers Dark Fantasy. Les joueurs peuvent découvrir des boosters, gérer leur panier et, dans les prochaines étapes, ouvrir des boosters, collectionner des cartes et composer leur propre deck.

## 🔗 Liens du projet

- **Site web (Vercel) :** [https://mythoria-card-game-phi.vercel.app/](https://mythoria-card-game-phi.vercel.app/)
- **Dépôt GitHub :** [https://github.com/AyoubHs0/mythoria-card-game.git](https://github.com/AyoubHs0/mythoria-card-game.git)
- **Planification du projet (GitHub Projects) :** [https://github.com/AyoubHs0/mythoria-card-game/projects](https://github.com/AyoubHs0/mythoria-card-game/projects)

## 🎯 Objectifs du projet

- Créer une interface immersive inspirée de l'univers Dark Fantasy.
- Présenter les boosters disponibles dans une boutique.
- Permettre au joueur de gérer son panier.
- Développer un système d'ouverture de boosters avec des cartes aléatoires.
- Permettre au joueur de consulter sa collection dans « Mon Grimoire ».
- Permettre la création et la gestion d'un deck de 20 cartes maximum.

## ⚙️ Fonctionnalités

### 🛒 Boutique

- Affichage des boosters disponibles.
- Présentation des informations et des prix.
- Ajout des boosters au panier.
- Calcul du total du panier.
- Suppression des articles et gestion du panier.

### 🎁 Ouverture des boosters

- Consultation des boosters disponibles à l'ouverture.
- Génération aléatoire de cartes à partir du catalogue JavaScript.
- Affichage des cartes obtenues.
- Ajout des cartes obtenues à la collection du joueur.

### 📖 Mon Grimoire

- Affichage des cartes collectées.
- Présentation des informations de chaque carte.
- Ajout des cartes au deck.

### 🃏 Mon Deck

- Affichage des cartes sélectionnées.
- Possibilité d'ajouter plusieurs exemplaires d'une même carte.
- Limite de 20 cartes.
- Suppression individuelle des cartes du deck.

## 🛠️ Technologies utilisées

- **HTML5 :** structure des pages web.
- **Tailwind CSS :** mise en forme et design responsive.
- **JavaScript :** interactions, gestion du panier, ouverture aléatoire des boosters et gestion des cartes.
- **LocalStorage :** conservation locale des données du joueur.
- **Git et GitHub :** gestion des versions et collaboration.
- **GitHub Projects :** planification et suivi des tâches.
- **Vercel :** hébergement du site web.

## 🚀 Installation et lancement

**1. Cloner le dépôt GitHub :**

```bash
git clone [https://github.com/AyoubHs0/mythoria-card-game-naruto.git](https://github.com/AyoubHs0/mythoria-card-game-naruto.git)
```

**2. Entrer dans le dossier du projet :**

```bash
cd mythoria-card-game-naruto
```

**3. Ouvrir le fichier `index.html` dans un navigateur**, ou utiliser l'extension Live Server de VS Code.
